== ROOT CAUSE of the earlier "stub" runs (now fixed) ==
A diagnostic app proved `tower.secret("hack")` returned a value but
`tower.secret("NIMBLE_API_KEY")` returned len=0 — i.e. the NIMBLE secret had been stored
CORRUPTED (empty) when first created by piping a shell variable into `--value`. Fix:
  tower secrets delete NIMBLE_API_KEY
  tower secrets create --name=NIMBLE_API_KEY --value=<clean 64-char key>
After the recreate, a probe showed `tower.secret("NIMBLE_API_KEY") len: 64`, and the pipeline
run above went live. Lesson: verify a secret round-trips (probe its length) after creating it.
